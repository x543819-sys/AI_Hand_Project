# AirPresent v0.7 · 当前页 AI 摘要

在 v0.6 稳定翻页与悬浮控制基础上，加入可手动触发的视觉摘要工作流。

## 新功能用法

1. 关闭旧助手，重新运行原项目 run.bat，连接正在放映的 PPT。
2. 从主面板或悬浮条点击「AI 摘要」。打开弹窗会暂停手势；摄像头预览继续。
3. 点击「预览本页（不联网）」检查页码和图片，无需密钥。页面来自绑定文稿，不截摄像头或桌面。
4. 选择智谱或 Kimi，填写对应账号的 API Key，可修改视觉模型名称。点击「生成 AI 摘要」会把这一页图片发送给所选服务，可能产生 API 费用。
5. 摘要包含主题、关键点和口头讲稿，可复制。点击「继续演示」关闭窗口并启用手势；普通关闭保留暂停状态。摄像头未开启时需先回主面板开启。

API Key 只保存在本次进程内，不写文件或诊断记录；也可由环境变量 AIRPRESENT_LLM_API_KEY 提供。切换服务应填写该服务的密钥。ai_settings.json 仅保存服务名和模型名。

重复请求同一页面可使用本次运行中的缓存；图片内容、文稿、页码、模型或提示变化会失效。失败不自动重发，由用户选择重试。关闭弹窗可丢弃结果；已发出的网络请求不能保证撤回，后台请求结束前不会启动新摘要。

导出的是页面静态内容，可能含尚未播放的动画对象，不是屏幕当前动画帧；本版不转写视频。摘要由模型生成，应核对数字。弹窗是置顶窗口，会显示在同一屏幕的放映上方；不是演讲者私有视图。

## 模型与验证

默认提供智谱 glm-4.6v-flash 与 Kimi kimi-k3.1-pro；模型权限、名称和价格以账号与官方文档为准。

- [智谱视觉接口](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-4.6v)
- [Kimi 视觉输入](https://platform.kimi.com/docs/guide/use-kimi-vision-model)
- [Kimi 模型列表](https://platform.kimi.com/docs/models)
- [Kimi 请求地址与密钥](https://platform.kimi.com/docs/get-api-key)

本机已通过真实专用 PPT 导出、弹窗、模拟模型成功/失败、复制及继续演示测试。尚未使用真实密钥调用服务，不能据此声明摘要质量或真实延迟已验证。双手 T 触发为下一步，当前从按钮触发。


# v0.6 翻页功能说明

本版修复启用状态容易丢失、松开后必须摆标准手势才能继续的问题，并增加放映上方的悬浮控制条和小图标。

## 使用

1. 打开 PPT 并开始放映，运行 run.bat，连接目标文稿。
2. 可先用上一页／下一页按钮检查真实页码变化，再开启摄像头。
3. 启用一次控制即可连续操作：拇指捏食指下一页，拇指捏中指上一页，松开后再次捏合。
4. 不需要每翻一页重新做剪刀手，也不要求松开后摆出张掌／剪刀手。程序直接使用有效手部的指尖分离证据。
5. 点击顶部「悬浮控制」收起主面板。摄像头继续处理，悬浮条保持在放映上方。
6. 点击悬浮条的「收成图标」变成小图标，点图标展开；点击「展开」回到主面板。

连接或启用控制后，悬浮条也会自动显示。它提供上一页、暂停／启用、下一页和展开按钮；显示当前手势、等待松开、切页中、等待手部或暂停状态。未开摄像头时启用按钮不可用，可展开主面板开启摄像头；已连接 PPT 的上下页按钮不依赖摄像头。

## 连续启用

默认关闭握拳自动暂停与丢手自动暂停，避免自然放松或手暂时离开画面后反复唤醒。短暂丢手或画面延迟时隐藏指示点、停止输出动作，保留启用状态；手返回后分开指尖即可继续。

主动按 Esc 或点击暂停仍会暂停。握拳／丢手自动暂停可在参数设置中重新打开。关闭摄像头、设备确实异常或重新连接目标也会改变控制状态，界面会给出提示。

捏合进入／退出采用两个距离阈值。松开只需要有效的指尖分离证据，即使该姿态被标为「调整手势」也可重新就绪；不确定或缺失的跟踪本身不当作一次松开，避免连翻。

## 动画与后台切页

切页请求在后台线程执行，不堵住摄像头和界面。PPT 暂忙会短暂自动重试；一次输出失败会显示原因并保留启用状态，可松开后再试，不需要重新剪刀手唤醒。

仍通过指定文稿的 GotoSlide 请求目标页，并读取页码确认。只有读取到页码变化才计入确认翻页。处理中的请求不会无限排队，悬浮条显示切页中。

本轮专用全屏测试包含 5 秒淡入动画，在动画结束前完成了切页。不同嵌入式视频、插件或 Office 忙碌状态可能有不同表现，不能据此保证所有文稿立即响应。

## 调参与诊断

捏合确认默认 160ms，松开确认 120ms，最短翻页间隔 300ms，可独立调整。旧版轻拨模式保留。启动后的控制状态、手势、页码结果均可在悬浮条查看。

导出诊断新增 pinch_released，用于区分是否已有松开证据。摄像头在本机处理，默认不保存或上传图像。推理耗时不等于端到端响应时间。
