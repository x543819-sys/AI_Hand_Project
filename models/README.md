# Hand Landmarker 模型

运行 `setup.bat` 或 `.venv\Scripts\python.exe main.py --download-model` 下载模型。

固定版本的官方模型地址：
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

文件保存为本目录下的 `hand_landmarker.task`。模型就绪后，正常使用无需联网。
来源与用途说明：https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker
